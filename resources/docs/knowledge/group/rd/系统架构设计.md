# RAGStudio 系统架构设计文档

## 一、概述

### 1.1 系统定位
RAGStudio 是面向企业级应用的 Agentic RAG（检索增强生成）平台，提供从文档入库到智能问答的完整管线，支持多模态文档解析、多通道混合检索、Agent工具调用和全链路可观测性。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 模块化 | 按功能域拆分为独立模块，接口清晰，低耦合 |
| 可扩展 | 检索策略、工具类型、模型协议均采用策略模式和注册制 |
| 高性能 | 异步非阻塞IO，多级缓存，并行检索 |
| 可观测 | 全链路追踪，关键路径日志，性能指标采集 |
| 安全 | 沙箱隔离、输入校验、API Key安全存储 |

## 三、核心模块

### 3.1 Framework 模块
**定位**：跨模块共享的基础类型和约定

```
framework/
├── convention/          # 通用DTO和枚举
│   ├── ChatMessage      # 通用消息模型
│   ├── ChatRequest      # 通用请求模型
│   ├── ChunkType        # 分块类型(TEXT/IMAGE)
│   └── TraceStatus      # 追踪状态
└── trace/               # 追踪基础定义
```

### 3.2 Infra-AI 模块
**定位**：AI基础设施，模型调用和协议适配

```
infra-ai/

│   ├── RoutingLLMService # 智能路由服务
│   └── client/          # 各厂商实现
```

## 四、关键数据流

### 4.1 对话查询流程

```
用户提问
    │
    ▼
StreamChatPipeline
    ├── 1. 登录校验
    ├── 2. 上下文构建 (AgentContext)
    │       ├── KB相关性判断 (KBRelevanceJudge)
    │       ├── 对话历史加载
    │       └── 系统 Prompt 构建
    ├── 3. Agent 循环 (AgentLoop)
    │       ├── LLM 调用 (RoutingLLMService)
    │       │       └── 多模型路由 + 熔断降级
    │       ├── 响应解析 (ReActResponseParser)
    │       │       └── JSON → AgentStep
    │       ├── 工具执行 (ToolRegistry)
    │       │       ├── rag_search → 检索引擎
    │       │       ├── web-search → 联网搜索
    │       │       ├── skill_* → 用户自定义工具
    │       │       └── mcp_* → MCP协议工具
    │       └── 结果注入 (Observation)
    ├── 4. 后处理
    │       ├── 引用溯源 (Citation)
    │       ├── SSE 流式输出
    │       └── 全链路追踪记录
    └── 5. 记忆存储
```

### 4.2 文档摄取流程

```
文档上传 (S3 / URL / File / Feishu)
    │
    ▼
FetcherNode (文件获取)
    │
    ▼
ParserNode (文件解析)
    ├── Tika → XHTML → Markdown (文字)
    ├── Tabula → CSV/Markdown (表格)
    └── Vision → base64 → 多模态模型 (图片文字)
    │
    ▼
ChunkerNode (智能分块)
    ├── 固定大小分块 (512 tokens)
    ├── 结构感知分块 (Markdown)
    └── 递归分块 (多级分隔符)
    │
    ▼
IndexerNode (Embedding + 入库)
    ├── Text → TextEmbedding → pgvector
    └── Image → ImageEmbedding → pgvector
```

## 五、技术选型

### 5.1 数据库

| 组件 | 选型 | 理由 |
|------|------|------|
| 业务数据库 | PostgreSQL 16 | JSONB支持、成熟稳定、生态丰富 |
| 向量数据库 | pgvector 0.7+ | 与业务DB统一、减少运维复杂度 |
| 全文检索 | PostgreSQL tsvector | 中文分词(zhparser)、与向量检索混合使用 |
| 缓存 | Redis 7 + Redisson | 分布式锁、缓存、消息队列 |
| 消息队列 | RocketMQ 5.x | 文档摄取异步化、削峰填谷 |

### 5.2 AI模型

| 场景 | 推荐模型 | 备选模型 |
|------|---------|---------|
| 对话生成 | Qwen3-Plus / DeepSeek-V3 | Qwen3-235B, Claude 3.5 Sonnet |
| Embedding | Qwen3-Embedding-8B (1536d) | text-embedding-3-large |
| Rerank | BaiLian gte-rerank | Cohere Rerank v3 |
| 多模态 | Qwen3-VL-Plus / DeepSeek-VL | GPT-4o, Claude 3.5 |
| 推理增强 | DeepSeek-R1 | QwQ-32B |
