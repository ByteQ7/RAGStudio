# System Info SKILL

## 功能
查询运行 RAGStudio 的服务器的基本系统信息。

## 使用场景
- 用户询问服务器主机名、操作系统版本时使用
- 用户询问 CPU、内存、磁盘资源占用情况时使用
- 排查服务运行环境问题时使用

## 返回字段
脚本输出包含以下信息：
- 主机名（hostname）
- 操作系统与内核版本（OS / Kernel）
- CPU 核心数
- 内存总量、已用、使用率
- 磁盘总量、已用、使用率

## 使用建议
1. 该技能无需参数，直接调用即可
2. 返回的信息可用于判断服务器负载状况，辅助回答用户关于部署环境的问题
